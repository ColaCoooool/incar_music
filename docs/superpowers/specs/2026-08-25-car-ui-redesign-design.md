# 设计：车机 UI 重构（v2）

日期：2026-08-25
状态：已批准（用户经视觉伴侣逐项确认：布局 C · 播放页 A · 配色 A）

## 背景与目标

现有 UI 是手机竖屏模板套在车机上：触控目标小（44-48px）、字号小（14-15px）、对比度不足（#aaa 次要文字）、布局为底部导航 + 迷你播放条。重构为符合车机主流设计规范（Google Design for Driving / CarPlay / 国内车机 App）的横屏体验。

核心原则：深色恒定、高对比、触控目标 ≥ 64px、正文 ≥ 17px、信息减密度、一屏一任务。

## 1. 整体布局（Dock + 常驻播放条）

```
┌────┬──────────────────────────────────────┐
│ ▷  │         内容区（卡片化）              │
│ ▤  │   曲库 / 歌单 / 设置 / 播放           │
│ ☰  │                                      │
│ ⚙  │                                      │
├────┴──────────────────────────────────────┤
│ 🎵 封面 | 歌名 · 歌手        ⏸    ⏭      │  ← 常驻播放条
└───────────────────────────────────────────┘
```

- 左侧 Dock（72px 宽，`min-width: 768px` 视口显示）：4 个导航项（播放/曲库/歌单/设置），44px 圆角图标按钮（触控 44px 为视觉，间距保证 64px 有效触控），当前项绿色高亮。
- 底部常驻播放条（72px 高）：小封面 48px 圆角 + 歌名/歌手（省略号）+ 大播放/暂停键 52px 圆形 + 下一首按钮。点击条身（除按钮）跳转播放页。
- 手机竖屏（`<768px`）：Dock 隐藏，回退为现有底部导航 + 迷你播放条（保持竖屏可用性，不浪费空间）。

## 2. 播放页（左封面 + 右歌词）

- 布局：`display:flex` 横排；左大封面（300px、圆角 16px、投影），右侧歌词区垂直居中滚动。
- 歌词：当前行 20px 加粗 + 绿色高亮 + 背景条；其余行 16px 次要色；`scrollIntoView` 保持当前行居中（现有逻辑保留）。
- 底部控制条（常驻，72px）：进度条加粗至 6px、时间 14px、大圆播放键 64px、上/下一首 52px。
- 竖屏回退：封面 220px 上置，歌词区其下（现有结构微调）。

## 3. 组件尺寸与设计令牌

| 令牌 | 现值 | 新值 |
|------|------|------|
| 触控目标（按钮/行） | 44-48px | ≥ 64px |
| 正文 | 14-15px | 17-18px |
| 次要文字 | 12px / #aaaaaa | 14px / #c9c9c9 |
| 标题 | 24px | 22-26px（视页面） |
| 列表行高 | 72px | ≥ 76px（封面 52px） |
| 卡片圆角 | 12px | 16px |
| Dock / 播放条高度 | 64px | 72px |
| 进度条 | 4px | 6px |

CSS 变量（main.css :root）新增/调整：`--dock-width: 72px`、`--bar-height: 72px`、`--touch-min: 64px`、`--text-secondary: #c9c9c9`、`--radius-lg: 16px`；保留品牌绿 `--accent: #1db954`。
